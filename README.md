# Fitness Club Database

Проект описывает базу данных для фитнес-клуба. В ней хранится информация 
о клиентах, тренерах, абонементах, тренировках и посещениях зала.

База данных решает проблему учёта клиентов и их активности: позволяет 
отслеживать, какие абонементы оформлены, кто из тренеров ведёт какие 
тренировки, кто из клиентов их посещает, и как часто люди ходят в зал. 
Это помогает администрации контролировать загрузку, продлевать абонементы 
и анализировать популярность тренировок.
